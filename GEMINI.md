# Proje Kuralları

- **Otomatik Git Commit & Push**: Bu projede herhangi bir kod, stil veya dosya değişikliği yapıldığında; değişiklik tamamlanır tamamlanmaz terminalden otomatik olarak `git add .`, `git commit -m "..."` ve `git push origin main` komutları çalıştırılarak değişiklikler hemen GitHub'a (`https://onder-altintas.github.io/mfkurs/` / `https://github.com/onder-altintas/mfkurs`) gönderilmelidir.
- Kullanıcıdan manuel olarak git komutu girmesi veya push yapması asla istenmemeli, işlemler asistan tarafından doğrudan yürütülmelidir.
